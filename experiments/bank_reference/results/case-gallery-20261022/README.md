# Existing PM case cards

This is an illustration export of already-archived results, not a new diagnostic
round. See [the Chinese gallery](../../../../docs/PM_CASE_GALLERY_ZH.md) and
[paper reading guide](../../../../docs/PAPER_READING_GUIDE_ZH.md).

- `pm_case_cards.pdf`: four pages for discussion.
- `01`–`03`: actual saved candidate times/keys, future-attention labels, losses,
  and covered scored coordinates. No RGB or physical-state reconstruction.
- `04`: the existing A2 aggregate conclusion and original small-effect limit.
- `selection_protocol.json`: deterministic, explicitly retrospective selection.
- `selected_cases.json`: unmodified selected rows and old A2 conclusion.
- `population_counts.json`: denominators for all 864 original parent rows.
- `render_manifest.json`: source and generated artifact hashes.

Zero residual is an auxiliary reference with no bank; the PaFu-versus-local-oracle
branches have identical K, inputs, reader and objective. The all-population
online negative result is not replaced by the selected successful snapshot.
