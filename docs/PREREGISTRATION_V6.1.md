## 判定规则

- **统计单位**：按 episode（VSC 按视频）做配对 bootstrap，1000 次，95% 分位区间。
- **下界类主张**（如 gap ≥ 0.3）：点估计达到阈值，且 CI 下端 > 0。
- **非劣类主张**（如 ≥ −0.1）：点估计达到阈值，且 CI 下端 > 该阈值。
- **比值类主张**（H3 闪烁伪变化率比）：点估计 ≤ 0.5，且 CI 上端 < 1。
- **种子规则**：
  - T0 用 oracle key，3 个噪声水平各 3 个噪声种子，每个水平至少 2 个种子通过；
  - T1/T2/T3 用 5 个 φ 种子，至少 4 个通过；
  - 学习门的种子与 φ 种子一一配对。
- **缺失**：缺失证据记为 `missing`，不算通过。

## 标定与固定参数

- **标定量**：
  - π = 10⁻³（每次写入；稳健性检验 10⁻⁴、10⁻²），VSC 取 5×10⁻³；
  - $\bar s$ 在 {0.05, …, 0.95} 上做 ML-II；
  - $d_k$ 取 {64, 128, 256, 512} 中最小的、使 A6 的 STAT 增益达到 oracle-key A6 增益 80% 的值；
  - ℓ 截断在 ±50。
- **数据**：
  - 9x9；train 取 sha1 序前 12000 条；dev 为 sha1 % 29 == 0；
  - 每个条件 dev 500 条、test 1000 条；
  - L1 参数见 `prereg.L1`；
  - 训练超参见 `prereg.TRAIN`。

## 相对调研报告提议的定稿选择

1. **H1 判 A8g，不判 A8**：A8 在全局 CHANGE 上必然付出每个旧 key 一次的陈旧误差。合成 one-hot 世界中 A8g 为 (0.88, 0.96)，A8 为 (0.30, 1.00)。局部性交给 H4。
2. **种子规则**：采用"5 中 4"，不采用"每个种子"；T0 采用"每个水平 3 中 2"。
3. **T0 的学习门**：只在 0.5 拟合一个种子，作描述。
4. **A1BF 的"不差于"**：容差定为 0.01。
5. **H3 的比值 CI 规则**：CI 上端 < 1。
6. **VSC 校准源**：用 50 个 10 分钟视频中 sha1 最小的 10 个，不参与 FINAL 计分。
