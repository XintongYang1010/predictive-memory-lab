## 1. 这个项目究竟想解决什么

核心问题是：**在有限记忆下，模型能否保留暂时看不见的对象状态；新证据到来时更新该对象，同时不破坏其他仍有效的历史？**

具体想象：A 与 B 曾分别向不同方向运动，随后被遮挡。现在的画面无法区分两种早期历史，模型需要依靠记忆预测它们将出现在哪里。若 A 重新出现并改变运动，模型应修正 A，继续保存 B 的旧状态。干扰物出现和经过更长时间，都可能使这个过程失败。

因此需要分开检查三件事：

- **保留：** 早期有用信息是否在遮挡和干扰后仍可使用？
- **更新：** 新证据能否改变已过时的状态？
- **避免干扰：** 更新 A 会不会错误改写 B？

这不是已经解决的视觉世界模型，也不是已经证明的新 memory 算法。研究动机与某个实现是否有效，是不同层次。

## 2. 为什么经历 V1–V4，再到 V5

V1–V3 从 RealMotion 的旧预测 bank 出发，检验何时保留、重建或重置历史。已经跑过的 V2.1/V3 没有取得可靠部署收益。这个设定也不能直接回答长历史下对象状态如何持续存在。

V4 改成可控数值状态任务：直接提供可见对象的身份、位置和速度，比较窗口、FIFO、GRU、对象状态与解析跟踪。它把检测和对应困难拿走，先研究保留、更新与干扰；已知身份和恒速先验很强，不能把其中效果当作视觉记忆证据。详细背景见 [V4 协议](STATE_MEMORY_V4.md) 和实验时间线。

V4 的独立结果分支已记录 A100 Slurm615 正式三种子实验，T48 的 slot 对 GRU 有收益，但 T96 仍有漂移；外层与容器的 GPU UUID 不一致，资源绑定核验失败。旧“尚未正式 A100”描述已过时。该分支只有小型报告/日志，约343MiB原始完整包当时存于 Slack/服务器，**本次未将其检查点全包镜像到 GitHub**；历史地址和 SHA 见 [资产索引](WEB_PROJECT_ARTIFACT_INDEX.md)。

V5 再把输入换成 RGB，并使用冻结的官方 I-JEPA 编码器。这样开始接触真正的视觉表示困难，却也引入了一个更靠前的门槛：**在讨论记忆前，模型是否能从视觉特征读出基本的位置与运动？**

## 3. V5 的原设计与真实执行路径

原方案的概念路径：

```text
受控世界与合法 RGB 观察
  → 冻结 I-JEPA，逐帧编码
  → 空间 token / 原方案 4×4 池化
  → 时间预测器 P0 与历史读取
  → 有限容量的 recent / exact / compressed memory
  → 未来特征预测
  → 保留、干扰、更新及历史交换/清零评价
```

原方案准备了三种 writer（additive、gated additive、gated delta）× 两种 reader 条件 A0/A1/B0/B1/C0/C1，以及 full-history、recent-only、等字节 FIFO 和固定 writer 的 reader-only replay。详细定义以 [V5 协议](VISUAL_MEMORY_V5.md) 与代码为准。

**原完整链路没有跑通。** 首轮完成真实权重加载/profile 和特征 probe，但原 pooled 位移 probe 未过预设门槛，因此原 P0/history gate、六组 memory 主比较和原 reader-only replay 没有启动。

后续 V5.1–V5.8 是为解释这个前置失败开展的诊断，其中确实训练过诊断 reader、做过原型 memory/update 对照；这些不等于原六组架构训练已完成。V5.8 的实际路径尤其简单：

```text
同一批已缓存 raw I-JEPA 特征
  → 五种受控空间操作 R / H / BR / DR / DBR
  → 固定源图像特权 ROI + 固定二维 cosine 匹配
  → 位移、错向、正确位置排名和代价面
```

这里没有训练、原 P0 或原 memory writer。ROI 利用源图像颜色定位对象，是诊断特权；它并没有解决任意视频中的检测与对象身份。

## 4. 数据与指标应当怎样理解

原 V5 是合成 RGB 机制任务：两个带纹理目标和干扰区域，有受控的可见/遮挡日程及更新事件。成对世界保持近期观察等条件一致，让早期历史影响正确答案。没有声称覆盖真实视频、移动相机或任意物体。

V5.8 复用已反复查看的 **256 个 Dev world、512 个 episode、1024 个对象查询**。同一 world 的变体和对象不是独立世界。原 Test 没有开启；V5.6 的 Fresh64 是另外的对象组合确认，不能称为原 Test 或所有后续分析的独立确认。

| 名词 | 直观含义 | 容易误读的地方 |
|---|---|---|
| encoder | RGB → 空间特征 | 单图预训练不自动保证小位移的跨帧对应 |
| pooling / sampling / reconstruction | 平均、减少网格点、在点间重建 | 三者不同；V5.8 的 D 仍合并采样和双线性重建 |
| reader / matcher | 从特征读出目标状态或位移 | 本轮固定 cosine 与原训练型 reader 不是同一个模块 |
| writer | 把新信息写入有限记忆 | 当前 V5.8 路径没有它 |
| dx / dy RMSE | 预测位移与真实位移之差，单位像素 | 水平改善不意味着纵向或联合指标改善 |
| wrong sign | 非零预测朝真实运动反方向 | 零输出单列，不能偷偷混进或移出分母 |
| GT rank | 最近真实位移的候选在匹配代价排序中的名次 | 是离散候选排名，不是连续真值的可恢复信息量 |
| oracle / privileged control | 为诊断额外提供真值或定位信息 | 只能用于定位上界，不能当可部署方案 |
| bootstrap CI | 按 world 成组重采样的不确定区间 | 已知 Dev 上的探索区间，不等于独立确认或因果证明 |

## 5. 截至 V5.8 可以说什么

1. **当前空间操作与匹配器之间有可重复的失败。** 密集同相位网格上，4×4 平均比 2×2 平均差；对这两种密集场进行粗采样重建，都进一步损害匹配。共同内点上仍成立。
2. **两种操作存在交互。** 粗网格上 4×4 平均反而优于 2×2 平均，不能归纳为“一切平滑都坏”，也不能分配模块责任百分比。
3. **局部细节访问值得研究。** 先前对象区域对照、当前 raw 与 pooled 的差距提供了动机，但颜色 ROI/额外访问是强条件。
4. **原始表示与读出仍不完美。** 原 raw 仍有位移低估、排名和残余错误，不能说取消 pooling 就修复原任务。
5. **原 memory 收益尚未建立。** 还需在确实需要历史的任务上、固定预算和其他模块，验证相对简单记忆基线的收益。

不能说：encoder 已被证明坏了；约 90% 的运动信息被丢失；降低 latent MSE 就等于理解运动；某张可视化更清楚就证明更好；当前 bad case 证明 Cambrian-S 错误；所有旧 batch/帧序疑点都仍未排除。后续精确回放和批次补验已排查了多项实现疑点，见时间线。

## 6. 为什么现在先读论文

继续扫描滤波宽度、插值和网格，可能主要优化这个两帧诊断 matcher。现在已有足够具体的现象，应该先决定：**压缩时保存什么，哪些细节未来可能有用，读出如何识别可信的对象对应？**

优先阅读 Cambrian-1 的空间聚合、V* 的目标引导细节搜索，再用 TAPIR 理解对应与定位不确定性；Thinking in Space 提供中间状态诊断范式，FeatUp 提供空间重建思路。用户已读的 Cambrian-S 应特别检查 surprise 与未来可用性、写入时未知查询、KV 存储预算等问题。详见论文路线文档。

候选假设：**写入时不知道未来查询，在固定存储字节下，按对象对应/定位的不确定性保留局部细节，是否比仅按整帧 surprise 分配记忆更能维持遮挡后状态？**

这是研究假设，没有完成新颖性检索或验证。低 surprise 不必然意味着局部细节不重要；但保存高不确定性区域也可能只保存噪声，必须设置会推翻它的实验。

## 7. 下一轮实验的启动条件

先写一页方案，包含：固定坏例揭示的现象；拟改一个主要机制；明确的收益和失败预测；输入/存储/计算预算；基线；FIT/选择集/新确认集边界。

建议回到历史必要的遮挡、重现与更新任务，固定 encoder、reader 和字节预算，对比 uniform/FIFO、surprise、对象最新状态等简单策略与新策略。使用真实位置/身份或不压缩特征作为单独的诊断参照，而非隐藏地给新方法更强输入。报告对象状态准确性、变化对象恢复、未变化对象干扰、历史交换/清零结果及实际开销。

同一特征场的精确平移 versus 采样后重建平移仍是尚未执行的便宜控制。只有它会改变方法选择时才优先做；无需把每个旧坏例都解释完才读论文。现有 Dev 适合形成假设，正式确认需要没用于反复选方案的数据。

# 项目实验时间线：从预测库干预到视觉运动诊断

更新至 2026-10-10，依据各轮已保存的报告、逐例统计和核验收据整理。本文解释每一步为何发生、实际做了什么，以及下一步为什么改变。它不替代冻结协议或原始结果；V5 完整模型和大缓存的 GitHub Release 入口在各轮报告中，V1–V4 的独立分支及 V4 外部大包例外在下文明确列出。

**当前最重要的事实：原 V5 的 P0、history gate 和 memory 方法训练比较没有完成。** 首轮在特征门槛失败后停止；V5.1–V5.8 是为定位这一前置失败而进行的读出器、数据干预、对应和空间压缩诊断。后续保存的核读出器模型不是原 P0 或 memory writer 的训练检查点。V5.6 的更新 replay 也是有限状态接口的压力测试，不是原 memory 主实验。

## 阅读数值前先区分这些口径

- V1–V3 的 ES 是 RealMotion/AV2 预测评价；V4 是直接读取位置、速度和对象 ID 的合成状态实验；V5 是 RGB 经冻结 I-JEPA 后的视觉运动问题。三者不能直接比较分数。
- V5 中传统字段 `velocity_r2` 实际评分的是 **t6→t7 的观测位移**，含反射后的真实端点变化，不是生成器隐藏的瞬时速度。位置标签是 t7 位置。
- 后续 motion skill 逐坐标计算 `1 − MSE / mean((target − frozen FIT mean)^2)`，再平均四个运动坐标。水平 MSE 只平均 A_dx/B_dx。像素 RMSE 为归一化坐标 MSE 开方再乘 224。四轴 skill、两轴 dx RMSE 和位置 RMSE 不是同一指标。
- 一个 original-generator world 有两个配对 variants；512 episodes 通常只有 256 个独立 world。确认用 quartet 或多视图时，同 world 的视图仍不是独立样本。配对 bootstrap 保留整个 world；区间通常条件于已拟合模型，不包含重新抽 FIT 或重新训练的不确定性。
- 冻结 I-JEPA 使用 BF16 前向。转换为 FP32、FP32 池化、BF16 保存再转 FP32 缓存，不等于全 FP32 提取。特征张量的存储 dtype 不能单独说明模型计算精度。

## V5 后续 CPU probe 审查：正分是否只是位置先验？

**问题与执行。** 在原 128/128 已看缓存上检查固定 ridge 正则、单帧/重复帧、时间差分、raw 重新池化、原生成器反射与 RGB 可观察性；仅 Train 内分组交叉验证选择正则，Dev 用于诊断，不新增 GPU 或 Test。

## V5.5：对象因子干预与 lane 读出器

**问题与执行。** 在已看 Dev640–895 固定首帧，将末帧 A、B、黄色物体的位置各取原 t6/t7，组成 8 个端点。冻结全局 W；另仅用旧 FIT 拟合固定 lane 读出器：A 访问 pooled 上两行，B 访问下两行。保存同次 encoder 的原 tokens、池化前值和 canonical 池化值。GPU `.40`、CPU `.41`；随后 GPU `.42`、CPU `.43` 完成全量 batch4 补验。

**结果。** 原始 `000→111` 查询的 dx MSE 降 **29.78%**；至少一个目标水平错向的 episodes 从 **196/512 降为 139/512**，四轴 skill 0.4340→0.5799。对象因子分解显示 lane 增强自身目标响应、降低跨目标响应，黄色响应没有一致降低。844/1 两个方向恢复但幅度很小；761/1 仍双错；891/1 的 B 仍被其他变化压过。

**结论与边界。** 同一已有表示的读出方式可改进，但 lane 同时改变特征访问、核几何和有效正则；不能直接归因为“删除了无关 token”。空间 tokens 仍有全局上下文。Shapley 响应不是错误责任百分比；池化后保留约 9.98% 的 token 差分投影能量也不等于只保留约 10% 的运动信息。

**已解决的数值疑问。** 首轮原图 batch4、编辑图 batch12 的潜在混淆，后来用全部 4096 图像槽统一 batch4 排除：83,886,080 个 canonical 特征值逐位相等，三模型全部预测差为零。它不应继续列为这批结果未排除的原因。原 W 的帧交换反号、重复帧约零和非零跨帧项也否定了“只是两个独立单帧位置函数相减”的简化描述，但不保证预测正确。

## V5.7：正确 y 与简单度量改动能否救回 x？

**问题与执行。** 仅 CPU、旧 Dev 的 1024 个对象查询。第一组在六个已保存成本面上比较原二维搜索、正确 GT-y、零 y、循环 +37 donor 的错配 y 及 GT-x。第二组比较 raw16/pool4 × 不减均值/共享源均值/逐帧均值 × cosine/未归一化平方距离；无训练、无新数据。

**结果。** 提供正确 y 后仍由成本自主选 x：raw dx RMSE **1.534→1.562px**，变化区间跨零；pool **3.878→4.080px**，显著更差。原正确 x 有时被错误 y 补偿。GT 最近点在正确行的中位 rank 为 raw 5/25、pool 12/25。六个配对原点/度量设置都保留明显 raw/pool 差距；pool 逐帧均值＋L2 有小幅改善，但仍约 **3.744px**。

**结论与边界。** 不能只把水平错误归于选错 y；简单去均值或改平方距离不足以修复成本排序。GT-x 直接给了 x，它带来的 dx 接近真值不能算自主收益，只能考察没给的 dy。共享均值不改变 L2 成本的负控通过；均值本身不能被称为纯背景。此处是固定对应器，不是旧核回归或原 memory。

证据：[V5.7 报告](../results/wm/visual-v5_7-20261010/README.md)、[oracle/错配与排序](../results/wm/visual-v5_7-20261010/cost/report.json)、[12 组原点/度量](../results/wm/visual-v5_7-20261010/descriptor/report.json)、[相关原论文及未解决边界](V5_7_RELATED_WORK.md)。

## V5.8：把空间平均与粗采样重建拆开

**问题与执行。** 仅 CPU，复用同 raw、源 ROI、cosine、625 个候选。五组为：R 原 raw16；H 同相位密集 2×2 平均；BR 同中心密集 4×4 平均；DR 从 H 粗采样并双线性重建；DBR 从 BR 粗采样并重建，逐位等于旧 pool4。H 在评分前加入以控制 BR 的半格相位变化。各组直接在自己的物理网格插值。

**结果。** R/H/BR/DR/DBR 的 dx RMSE 依次 **1.534 / 1.520 / 3.392 / 4.808 / 3.878px**。同相位密集 BR−H 的 dx MSE 增加 **9.199px²**，95% CI [8.216, 10.233]；同一 2×2 场的 DR−H 增加 **20.811px²**。全部候选均不触网格边界的共同内点仍有 863/1024 查询、覆盖全部 256 world，方向一致。844/1 A 与 891/1 B 不需先粗采样，H→BR 就能从正确方向变错。

**必须同时保留的反例。** 粗网格上 DBR 优于 DR，dx MSE 差 **−8.081px²**，所以不能说平均普遍有害；平滑和采样的作用不相加。H 的水平差相对 R 未显著，且四轴 MSE 更差，H 也不是已证实的全面修复。

**结论与未排除项。** 已定位到这些空间压缩算子与当前固定 cosine 成本排序的耦合：较大平均范围、粗采样加重建均足以在这一设置下损害定位；边界复制不能单独解释。尚未分离采样与重建、证明具体频谱混叠机制、测定信息不可恢复程度或识别 encoder 某层故障。没有测试训练型读出能否恢复，更没有检验原 memory。未来的已知描述子场平移、像素平移等变性、学习型对应和查询选择仍是候选，未在本轮执行。

证据：[V5.8 报告](../results/wm/visual-v5_8-20261010/README.md)、[全部九个对比与计数](../results/wm/visual-v5_8-20261010/spatial/report.json)、[固定坏例](../results/wm/visual-v5_8-20261010/spatial/fixed_cases.json)、[结果独立复算](../results/wm/visual-v5_8-20261010/spatial_result_review.json)、[归因审阅](../results/wm/visual-v5_8-20261010/interpretation_review.json)。

# 从三个坏例理解：空间压缩后，对象为什么会被匹配到错误方向？

这三个案例说明的是：**同一份冻结视觉特征，经过不同的空间平均和网格重建，再交给同一个对应器，正确位移的排名会改变，甚至从正确方向变成反方向。** 它们帮助定位“空间处理＋当前对应规则”的失败；没有证明 encoder 内部哪一层出错，也没有证明原来的长期 memory 已经有效或无效。

案例编号是 `world / variant`。844/1、761/1、891/1 最早是 V5.4 按已评估 episode 的 W reader 水平误差选出的前三例，之后固定沿用，**不是根据 V5.8 的结果重新挑选，也不是总体的随机样本**。V5.8 的总体证据来自全部 256 个已知 Dev world、512 个 episode、1024 个对象查询，见[完整报告](../results/wm/visual-v5_8-20261010/README.md)。

## 先看实际输入，再分清测试的是哪一层

每张图为 224×224 像素，左边是 t=6，右边是 t=7。A 是上方红／橙色对象，B 是下方蓝色对象；中间黄色块是干扰物。任务中的真值来自生成器的连续位置，本文将归一化位移乘以 224，统一写成像素；它不必等于整数光栅边缘移动的距离。

![三个固定案例的原始 t6/t7 RGB](../results/wm/visual-v5_4-20261010/bad_cases/top3_bad_cases.png)

**这张原图拼图的文字标注属于 V5.4：N/W 是当时训练的两个 reader，数字采用归一化坐标；它们不是下文的五组对应预测。** 本文使用这张图展示原始画面和选例来源。六张 RGB 的哈希已经与编码输入核验；V5.4、V5.6 的六张图记录一致，三张 t6 图也与 V5.8 的源图记录一致。[原图核验](../results/wm/visual-v5_4-20261010/bad_cases/render_verification.json) · [V5.6 RGB 记录](../results/wm/visual-v5_6-20261010/correspondence_interpretation/rgb_hash_readback.json) · [V5.8 源图记录](../results/wm/visual-v5_8-20261010/spatial/source_rgb_records.json)

V5.8 实际经过的路径是：

```text
同一原始两帧 → 已缓存的冻结 I-JEPA 特征
           → R / H / BR / DR / DBR 空间处理
           → 固定局部余弦对应器 → 从 625 个候选中选位移
```

这里的 **raw 是 encoder 输出的 latent 特征，不是原始 RGB**。每帧为 16×16 个、每个 1280 维的空间描述子；来自同一次 BF16 encoder 前向，按 FP32 保存。一个空间 token 可以包含全局上下文，不能把它等同于仅看该像素块的独立对象特征。

对应器从**源图颜色**定位 A/B，各取包围框内 3×3 个点；这使用了已知任务颜色的特权信息。随后在两帧的特征场上比较这九个点，采用通道中心化后的余弦距离。它不使用目标帧颜色来寻找终点，也不是 V5.4 的训练型 reader。原项目的 history/P0 gate、memory writer、长期存取与未来预测均不在这条诊断路径中。

## 五组到底改了什么

| 组 | 存储网格 | 处理与查询方式 |
|---|---|---|
| R | 16×16 | 原 latent 特征；在原物理网格上双线性查询。 |
| H | 13×13 | 在半格中心取原特征场，等价于中央 2×2 平均；作为与 BR 同中心、同密度的参照。 |
| BR | 13×13 | 同样的中心，改为有效 4×4 窗口平均，再在密集网格查询。 |
| DR | 4×4 | 从 H 每隔四格取样，在该粗网格直接双线性重建和查询。 |
| DBR | 4×4 | 从 BR 每隔四格取样；复现 V5.6 的 CPU Pool 对照。 |

H 与 BR 的中心均为 `27.5 + 14j`；DR 与 DBR 的中心为 `27.5 + 56k`。`H[::4, ::4] == DR`、`BR[::4, ::4] == DBR` 已逐位验证。平均用 FP64 累加后保存为 FP32；这里的 DBR 复现的是同源 CPU pooling 对照，不能据此宣称它与原 GPU 流水线所有 BF16 池化缓存逐位相同。

因此，**BR−H 比较同相位、同密度下扩大平均窗口的影响；DR−H 与 DBR−BR 比较粗采样加重建的影响。** R−H 仍同时涉及取样位置、隐式平均和支持域，DR 也包含 2×2 插值平均；它们不是“纯相位”或“完全没有低通的抽样”。五组 token 数不同，本轮不是等字节内存竞赛。[算子协议](V5_8_EXECUTION_PROTOCOL.md)

H 在 A 上比 R 更接近真值，但在 B 上进一步低估水平位移。BR、DR 将 B 的水平位移反向，DBR 又恢复向右且二维误差小于 R。这样的结果是保留五组、两对象完整输出的原因：**总体劣势允许局部改善，不能把坏例讲成每一步都单调变坏。**

**能定位：** B 的所有候选都不触边，仍有 BR/DR 的反向；说明本例并非只能由边缘解释。同时，DBR 对 B 的改善展示平均窗口与粗采样之间存在条件关系。

**不能定位：** A 不属于五组共同无触边子集：虽然它的源点和最终选中的目标点未触边，部分其他候选会在 H/BR/DR/DBR 上触边。不能用 A 作为完全排除边界影响的示例，也不能依据此例单独决定最优压缩方法。[完整代价面](../results/wm/visual-v5_8-20261010/spatial/figures/case_761_1_costs.png)

## 如何理解 rank、错向和候选网格

- **625 个候选**是 `dx,dy ∈ {−6, −5.5, …, +6}` 的 25×25 组合，不是 625 个对象。对应器对每个候选比较九对特征，选平均余弦距离最小者。它输出 0.5px 的整数倍，连续真值通常不在格点上。
- **GT rank**先把连续 GT 映射到最近格点，再数有多少候选的代价严格更低；1 最好。行内 rank 限制在最近 GT y 的那一行，是用了真实 y 的特权诊断，不是可直接部署的新算法。rank 反映当前代价排序，不是 latent 信息含量。
- **错向**表示预测与真实位移的符号相反；**低估**表示同方向但绝对幅度不足；零预测另列。总体水平符号统计只计 `|GT dx|≥1px` 的 1022 个查询，未把零预测并入非零错向。
- **搜索边界**指选中 ±6px；**特征插值触边**指查询超过某组 token 网格的支持域。两者不是一回事。三个案例的 GT 均在搜索范围内，844/1 与 891/1 的全部候选又都不触特征边界。

候选离散化让精确命中连续真值并非必然，但五组共享同一候选表；它不能单独解释组间大幅方向变化。三例所有组的最小代价均无并列，也不是恰好在 tie-breaking 上选错。[逐对象 CSV](../results/wm/visual-v5_8-20261010/spatial/per_episode_object.csv)

## 回到项目：目前证据支持哪一步

全体对象查询的水平 RMSE 为 R 1.534、H 1.520、BR 3.392、DR 4.808、DBR 3.878px；共同无触边子集仍有同样的主要差异。**值得继续研究的是，怎样保留目标附近足够密的空间信息，并让读取规则稳定利用它。** H 的水平点估计略好于 R 不是已经验证的修复：其差值区间跨零，且四坐标平均 MSE 更差。

目前不能把失败全部分给 pooling、encoder 或 reader，也不能把采样与重建拆成已证实的责任比例。这里没有追踪遮挡后的持久身份，没有验证记忆写入是否保留预测所需信息，没有重跑或通过原 history/P0 gate。原图中黄色块在移动，但 **V5.8 没有改变黄色块**，这组三个案例也不能把黄块运动与错误的共现解释为因果。

# 从坏例到论文：空间证据、对应定位与预测记忆的阅读路线

本页供接手项目的网页助手、合作者和读者使用。**当前建议先暂停继续扩展消融，把已有坏例解释清楚，再从论文中选择一个可证伪的机制。** 下面是阅读和设计建议，不是新实验登记；没有因此启动训练、GPU 作业或新的科学评分。

用户正在读 Cambrian-S。新的主线先读 Saining Xie 参与的 **Cambrian-1 → V* → Thinking in Space**，再回看 Cambrian-S 的 **§4 和 Appendix F.2**；与当前定位失败最直接相关的补充是 **FeatUp 和 TAPIR**。抗混叠论文作为可选背景。选择依据是它们能回答什么具体问题，不是作者名气，也不意味着这些想法具有新颖性。

## 先把项目的问题说准确

项目最初想研究：在有限记忆下，预测误差能否帮助系统保留之后有用的视觉证据。实际推进中，原 V5 的运动读出门槛失败，后续工作转向诊断“写入记忆之前，视觉表示和读出是否已经把小位移读错”。后续局部改善不等于原门槛通过，更不等于长期记忆有效。

阅读前先看以下三份证据，不必重读所有实验日志：

| 已有证据 | 它排除了什么简单解释 | 它没有证明什么 |
|---|---|---|
| [RGB 可观测性诊断](../results/wm/visual-v5_5-followup-design-20261010/rgb_observability/)：固定颜色质心可以从 RGB 较准确地读出位移 | 大量反向错误不能主要归咎于像素中完全没有运动信息 | 这是已知颜色的特权诊断，不是学习模型成绩，也不证明 encoder 的描述子可直接定位 |
| [V5.6 等字节局部对应](../results/wm/visual-v5_6-20261010/README.md)：源图颜色 ROI 附近的细节优于均匀粗池化；两帧变化优先策略大量选择黄色干扰物附近 token | “保留变化最大的 token 就会保留有用运动”在这条路径上不成立 | ROI 依赖特权颜色定位；变化优先使用两帧，不能称为在线选择；两帧缓存不是长期 memory |
| [V5.8 空间算子诊断](../results/wm/visual-v5_8-20261010/README.md)：同一 raw 特征上，大窗口平均和粗采样重建均可破坏当前 matcher 的定位 | 单用网格相位、插值触边或并列最小值解释失败不充分 | 没有证明信息不可恢复，没有定位 encoder 内某层，也没有测试训练型 reader 或 memory writer |

## 1. Cambrian-1：压缩的是 token 数，还是空间证据？

**正式信息。** *Cambrian-1: A Fully Open, Vision-Centric Exploration of Multimodal LLMs*，**NeurIPS 2024**；Shengbang Tong、Ellis Brown、Penghao Wu 等，**Saining Xie 为合著者及通讯作者**。[正式论文页](https://proceedings.neurips.cc/paper_files/paper/2024/hash/9ee3a664ccfeabc0da16ac6f1f1cfe59-Abstract-Conference.html)；[原文 HTML](https://arxiv.org/html/2406.16860v1)；[作者项目页](https://cambrian-mllm.github.io/cambrian-1/)。

**重点读。** §4 *Spatial Vision Aggregator (SVA): A New Connector Design*，尤其 Fig.8 与该节的 connector／token 数消融表；需要理解评估背景时，再补 §3.1–3.2。不同版本的表号可能变化，以章节与表题定位。

**论文证据。** SVA 用具有空间聚合范围的可学习查询，通过 cross-attention 聚合视觉特征，并在 LLM 的多个层次再次访问视觉信息。论文比较的是 MLLM 的连接器及视觉理解表现，不是我们的两帧小位移测量。

**对应坏例与我们的推断。** 844/1 A 提醒我们：把邻域压成一个固定均值，可能改变当前位置与邻近背景的相对证据。SVA 值得学习的部分是“每个压缩 token 从哪里读、允许怎样混合”，而不是直接照搬多 encoder 或完整 LLM。输出 token 数相同，也不保证保留下来的空间信息相同。

**额外信息与预算。** 学习聚合需要训练；反复 cross-attention 需要保留、访问上游视觉特征并付出计算。多视觉塔还改变 encoder 成本。不能只报 LLM 输入 token 数而忽略原特征缓存、聚合器参数、训练数据和重复读取成本。

**可证伪控制，尚未执行。** 固定 encoder、可访问的原特征、输出字节数和训练集，对比固定平均与带空间范围约束的聚合；在未使用过的世界测方向、幅度及干扰变化。如果改善只在额外保留全部高分辨率特征时出现，就不支持“相同总预算下的压缩修复”。若同预算下方向仍反复出错，也不能仅凭最终 VQA 分数宣称定位已恢复。

**讲解检查点。** 能否分别指出 query 的空间位置、它能访问的特征范围、输出 token 的含义，以及被省略的缓存费用？

## 2. V*：让任务需求决定细看哪里

**正式信息。** **V*: Guided Visual Search as a Core Mechanism in Multimodal LLMs**，**CVPR 2024**（预印本 2023）；作者 **Penghao Wu、Saining Xie**。[正式论文页](https://openaccess.thecvf.com/content/CVPR2024/html/Wu_V_Guided_Visual_Search_as_a_Core_Mechanism_in_Multimodal_CVPR_2024_paper.html)；[原文 HTML](https://arxiv.org/html/2312.14135v2)。

**重点读。** §3.1 的 SEAL／Visual Working Memory，§3.3 的搜索流程及 Algorithm 2；先跟踪“已有问题 → 需要找的对象 → 搜索区域 → 局部证据 → 回答”，再看搜索模型训练。

**论文证据。** V* 用语言模型给出的目标和上下文引导高分辨率图像搜索，把搜索得到的局部证据与全局图像、目标位置组织为 VWM，再供问答模型使用。这里的 VWM 是该搜索问答流程中的信息组织方式。

**对应坏例与我们的推断。** V5.6 的变化优先策略经常围绕黄色干扰物分配细节；它衡量“变化大”，没有衡量“对 A/B 位移有用”。V* 提供的是需求驱动的搜索思路。已有颜色 ROI 的收益可以提示局部选择值得研究，但颜色已知的 ROI 不是学出来的搜索策略。

**额外信息与预算。** V* 搜索时已知道问题，还能访问原始高分辨率图像并反复裁剪／查询。我们的 memory 如果要服务未知的未来问题，就不能在写入时偷偷使用那个问题；如果原图已丢弃，也不能免费回头放大。搜索调用数、裁剪编码、原图保留、位置元数据和工作区都要计费。

**可证伪控制，尚未执行。** 将“查询已知时的选择”和“查询未知时的写入”分成两个任务。前者固定搜索次数和总字节，比较任务引导、均匀与变化优先；后者必须先冻结写入，再揭示未来问题。若收益依赖提前知道答案对象或不计费回看 RGB，就不能声称解决了未知查询的长期记忆选择。

**讲解检查点。** 在原算法的哪一步问题已经给定？映射到项目时，哪些信息在写入时实际不可得？

## 3. Thinking in Space：用什么证据才配称为空间记忆？

**正式信息。** *Thinking in Space: How Multimodal Large Language Models See, Remember, and Recall Spaces*，**CVPR 2025**（预印本 2024）；Jihan Yang、Shusheng Yang、Anjali W. Gupta、Rilyn Han、Li Fei-Fei、**Saining Xie**。[正式论文页](https://openaccess.thecvf.com/content/CVPR2025/html/Yang_Thinking_in_Space_How_Multimodal_Large_Language_Models_See_Remember_CVPR_2025_paper.html)；[原文 HTML](https://arxiv.org/html/2412.14171v1)。

**重点读。** §2 的能力分解、§3 的 VSI-Bench 任务定义，以及 **§6.1–6.2 的 cognitive maps**、对应地图可视化与相对距离结果表。不要只看总平均分；区分自我中心视角、环境坐标中的关系和语言回答。

**论文证据。** 工作构建视频空间评估，并用生成的认知地图探查模型的空间组织能力；在其相对距离实验中，先生成地图可改善回答。论文也讨论局部空间意识与统一全局空间表达的差距。

**对应坏例与我们的推断。** 我们当前甚至存在 A/B 水平运动的符号串扰；解决它只是局部感知条件。即使两帧读出准确，也没有证明同一对象在换视角、离开画面、再出现之后仍保持身份和空间关系。此论文最适合帮助定义项目最终应验证的能力，而不是为当前 toy 实验附加“world model”名称。

**额外信息与预算。** 显式地图、对象坐标、关系边、生成地图的推理步骤都占用存储和计算。GT 地图是额外真值，模型生成地图与 GT 地图的结果必须分开。真实室内视频与当前合成场景也不是同一分布。

**可证伪控制，尚未执行。** 在局部可观测性成立后，用相同最后画面、不同历史的成对任务验证历史是否改变答案；再检查对象重现和视角变化的关系一致性。若最后一帧或单帧位置先验已能解释收益，就不足以支持 memory 的因果贡献；一张看似合理的地图也不能代替这种对照。

**讲解检查点。** “看见”“保存证据”“更新当前状态”“用状态回答关系问题”分别需要哪个独立观察？

## 4. 已读 Cambrian-S：回到 §4 和 F.2，而不是重读全文

**正式信息。** *Cambrian-S: Towards Spatial Supersensing in Video*，**2025 预印本**；Shusheng Yang、Jihan Yang 等，**Saining Xie 为合著者**。本页使用已核验的 v1，不推断后续会议版本。[论文记录](https://arxiv.org/abs/2511.04670)；[原文 v1](https://arxiv.org/html/2511.04670v1)。

**重点读。** §4 *Predictive Sensing as a New Paradigm*，尤其 §4.1 的 latent frame prediction、§4.2 的 memory 用法；随后逐项读 **F.2：Basic memory units → Streaming sensing → Compression → Consolidation → Retrieval**。暂不把 F.3 的计数系统混入同一个实现解释。

**论文证据。** 预测下一帧 latent 的误差提供 surprise 信号。F.2 的基本记忆单元是各 LLM 层的 KV，而不是直接储存视觉 encoder 的 raw feature；框架区分 sensory、long-term 和 working memory，并定义压缩、整合与检索流程。

**对应坏例与我们的推断。** 变化优先追逐黄色干扰物，使我们必须问：预测误差是任务相关的新证据，还是不值得保留的变化？但 V5.6 测的是相邻帧特征变化，**不是论文训练出的 latent prediction error**；不能据此宣布 Cambrian-S 的 surprise 无效。更基础的问题是：当读出已反向时，记忆是在保存错误证据，还是在后续步骤中有机会纠正它？

**额外信息与预算。** LLM KV、预测头、各层缓存、检索工作区与视觉 raw token 不是相同对象；不能用 raw 特征字节直接替代论文 KV 费用。预测器训练、历史窗口、query 到来时间也必须明确。压缩旧证据与修正当前对象状态是不同操作。

**可证伪控制，尚未执行。** 待基础读出条件满足后，在同一 predictor／reader 下，按相同完整字节预算比较 surprise、recency、uniform；预先定义任务相关事件与无关变化，并检查后续回答是否因相应证据的保留／移除而改变。若 surprise 只多保留干扰变化，或移除所谓关键记忆不影响后续回答，就不支持“保留了因果有用的记忆”。

**讲解检查点。** 请沿一段新视频证据逐步追踪它何时变成 KV、何时被压缩、何时进入长期记忆、何时被 query 检索；再指出我们的实现目前真正走到了哪里。

## 5. FeatUp：空间重建需要什么额外约束？

**正式信息。** *FeatUp: A Model-Agnostic Framework for Features at Any Resolution*，**ICLR 2024**；Stephanie Fu、Mark Hamilton、Laura E. Brandt、Axel Feldmann、Zhoutong Zhang、William T. Freeman；**不含 Saining Xie**。[正式论文页](https://proceedings.iclr.cc/paper_files/paper/2024/hash/c5601d99ed028448f29d1dae2e4a926d-Abstract-Conference.html)；[原文 HTML](https://arxiv.org/html/2403.10516v1)；[作者项目页](https://mhamilton.net/featup.html)。

**重点读。** Fig.2，§3 的多视图一致性，§3.1 *Choosing a Downsampler*，§3.2 *Choosing an Upsampler* 中的 joint bilateral upsampling（JBU），以及该版本 §6.13 *Limitations*。

**论文证据。** 对同一图像施加已知变换，利用冻结 backbone 的多个低分辨率观测约束高分辨率特征。JBU 使用 RGB 引导混合邻近特征；另一种隐式表示需要对单图进行拟合。论文也报告纹理转移／halo 等局限。

**对应坏例与我们的推断。** 844/1、891/1 的局部成本排序在平均后恶化，提示“压缩与重建是否保留定位所需的几何”值得直接约束。FeatUp 的价值是训练目标和几何一致性，而不是把 4×4 resize 到 16×16 后就称为恢复信息。

**额外信息与预算。** RGB 引导、多次变换后的 encoder 前向、上采样器训练或每图拟合，都是额外资源。仅从同一份 coarse token 恢复，与借助 RGB／多视图恢复，是两个不同问题。单图变换一致性不等于真实跨帧时序一致性；更清晰的特征可视化也不等于更准确的位移。

**可证伪控制，尚未执行。** 先用固定描述子场的已知平移检查重建和度量，再考虑仅在 FIT 上训练的几何一致性模块。固定 matcher 和完整资源预算，在新世界比较方向、幅度及正确候选排名。若只变得视觉上锐利、定位并不改善，或收益完全来自新增 RGB 而非已压缩特征，就必须收窄机制结论。

**讲解检查点。** 每一项细节来自 coarse feature、RGB、变换后的新观测，还是训练先验？不能把来源统称为“上采样恢复”。

## 6. TAPIR：代价面初始化不等于最终定位

**正式信息。** *TAPIR: Tracking Any Point with Per-Frame Initialization and Temporal Refinement*，**ICCV 2023**；Carl Doersch、Yi Yang、Mel Vecerik、Dilara Gokay、Ankush Gupta、Yusuf Aytar、João Carreira、Andrew Zisserman；**不含 Saining Xie**。[正式论文页](https://openaccess.thecvf.com/content/ICCV2023/html/Doersch_TAPIR_Tracking_Any_Point_with_Per-Frame_Initialization_and_Temporal_Refinement_ICCV_2023_paper.html)；[原文 HTML](https://arxiv.org/html/2306.08637v2)；[作者项目页](https://deepmind-tapir.github.io/)。

**重点读。** Fig.2，§3.1 *Track Initialization and Position Uncertainty Estimates*，§3.2 *Iterative Refinement*，§4 高分辨率扩展和 §5.3 消融。

**论文证据。** 先用查询点与帧特征形成成本体并初始化位置，再以局部、多尺度信息进行迭代细化，更新位置和查询表示；模型分别处理遮挡与定位误差风险。它使用专门训练的跟踪模型，不是冻结 I-JEPA 上直接取 cosine 极值。

**对应坏例与我们的推断。** 原 raw 仍有约 1.5px 水平 RMSE，891/1 B 即使方向正确也明显低估幅度。TAPIR 给出两个应分开思考的模块：局部修正，以及知道当前位置是否可靠。V5.7 中给定正确 y 仍未总体修复 dx，因此不能把问题简单化为减少二维搜索候选。

**额外信息与预算。** TAPIR 改变了 encoder／训练数据／匹配器，并使用时序细化；论文的监督训练和跨帧信息不是免费的。离线时序访问也不自动满足在线 memory 约束。成本最小值、峰值间隔或熵都不天然是校准后的失败概率。

**可证伪控制，尚未执行。** 固定输入特征和初始位置，仅增加预先规定的局部细化，独立报告“初始化已接近”与“初始化远离”两组；另用 FIT 校准定位风险，在新世界检查风险与实际误差是否对应。若靠更换 encoder 才改善，就不能归因为细化模块；若修正只能在 GT 初始化附近工作，也不能宣称解决搜索失败。

**讲解检查点。** 遮挡、位置不准和身份匹配错误为什么是不同事件？哪个输出能支持哪个判断？

## 可选：抗混叠不是“多平均一点”的口号

**正式信息。** Richard Zhang，*Making Convolutional Networks Shift-Invariant Again*，**ICML 2019**；**不含 Saining Xie**。[正式论文页](https://proceedings.mlr.press/v97/zhang19a.html)；[原始 PDF](https://proceedings.mlr.press/v97/zhang19a/zhang19a.pdf)。重点读 §3.1–3.2、Fig.2–4。

**论文证据。** 将下采样拆为密集操作和抽样，在抽样前插入低通滤波，以改善 CNN 的平移稳定性。特征随平移而移动的 equivariance，与分类结果不变的 invariance 是不同目标。

**对应坏例与边界。** V5.8 中密集 4×4 平均比密集 2×2 差，但粗网格中 4×4 比 2×2 好，与滤波效果依赖采样条件相容；这还不是对具体频谱混叠机制的识别。论文的 CNN 分类结果不能直接证明 I-JEPA 的小位移描述子会被 BlurPool 修好。

**可证伪控制，尚未执行。** 保持同一物理场、网格和预算，改变滤波核与采样相位，分别测已知平移下的重建误差和定位误差。若平移一致性改善而定位更差，就必须保留两种目标的冲突。滤波支持、边界规则和计算量都要记录，不能只按 token 数宣称等价。

## 从阅读返回设计前，必须做出的选择

这组论文支持三个不同层次的候选问题。**它们目前都不是新实验承诺。**

1. **空间表示与读出接口：** 以 Cambrian-1／FeatUp 为线索，问有限字节下怎样保留可定位的局部证据。优先区分固定特征中的采样重建问题，与真实跨帧描述子变化；不能同时换 encoder、聚合器和训练目标后只报告一个分数。
2. **有目的的选择与对应细化：** 以 V*／TAPIR 为线索，问在合法的可用信息下怎样找对位置、细化位移，并识别失败。需要把已知问题、RGB 特权 ROI、未来帧和额外高分辨率访问分别计入条件。
3. **历史证据何时因果有用：** 以 Thinking in Space／Cambrian-S 为线索，待基础视觉条件足够后再验证保留、更新和检索。必须有历史依赖对照，不能由两帧更准或视频问答更高直接推出长期 memory 有效。

在这之前，先能解释两个现象：为什么 844/1 A 在同相位密集平均后反向；为什么 891/1 B 在 raw/H 中仍低估幅度。解释要指出证据允许和不允许的范围，不能以“encoder 坏了”“pooling 丢失全部信息”代替可检验机制。

所有学习型选择都只能在训练数据上开发，已反复查看的 Dev 只能用于探索性诊断；后续确认要有未使用的世界及冻结方案。水平 dx MSE、四维平均 skill 和方向错误是不同指标；沿用哪一个冻结 FIT 均值作 skill 分母也必须明确，不能拿 Dev 方差偷偷替换。读取成本、存储、元数据、训练和额外原图访问都纳入预算。没有本页建议可以绕过原协议门槛。
