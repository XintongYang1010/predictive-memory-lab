## 读取与恢复边界

- 页面讲解先读 Markdown、PNG、CSV/JSON；无需下载数 GB 缓存。
- 本次阅读包含当前分支全部 Git 文件与讲解；旧分支的原始大档由以上固定提交链接提供。
- 既有 Release 大资产不重复塞进阅读包，精确下载入口保留在 JSON 盘点。
- 官方 encoder 权重与外部 AV2 数据不重新分发；依照各轮版本、哈希和重建说明取得。
- 不包含本机虚拟环境、SSH 配置、凭据、私人聊天导出或无关项目文件。
- 仓库保持私有；公开浏览器未登录返回不可见不等于资产缺失。
