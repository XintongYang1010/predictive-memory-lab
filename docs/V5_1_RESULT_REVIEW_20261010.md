## 复核结论

- 停止 P0 正确。确认集支持“登记的受控分布上，池化特征和冻结二次核读出器确实利用了双帧证据”。原分布 bridge 失败，不能外推到原任务可用性或记忆收益，也不能据此断言 I-JEPA 没有运动信息。
- 所查帧序、标签组装、FIT-only 核中心化和冻结预测路径没有发现新的阻塞性实现错误。独立数值重放增强实现可信度，但不是新的独立科学样本。
- 反射与非反射子组均失败，所以反射不能独自解释失败；反射的局部影响没有被排除。
- 特征通过 BF16 autocast 推理，转 FP32 池化，再将池化结果量化为 BF16；提取器随后转为 FP32 NumPy 缓存。缓存的 `float32` 是存储类型，不代表全 FP32 特征提取，也不会恢复已量化信息。目前没有证据说明精度导致失败。本地只读核实了冻结源码 `pmr/visual_memory/features.py:41–47` 和 `scripts/extract_v5_confirmation.py:123–126`，已有归档 README 没有误称全精度提取。
- bridge 中 t7 单帧控制得到正分，说明普通 bridge skill 本身不证明原分布中的时间利用。未来即使 bridge 转正，也应在原分布条件下增加匹配 anchor 对照。九项置信下界不能计作九项独立证据。
