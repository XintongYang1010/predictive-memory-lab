# V5.7 相关工作与诊断边界

二维对应、按目标读取视觉细节、查询历史记忆均已有直接先例。下列原论文于 2026-10-10 核实；这是针对当前问题的相关工作整理，并非穷尽的新颖性检索。

| 原论文 | 与当前问题的联系及区别 |
|---|---|
| [RAFT，ECCV 2020](https://arxiv.org/abs/2003.12039) | 以二维全对相关体和共享迭代更新估计光流，是空间对应读出的直接先例。直接换用完整 RAFT 同时改变编码器与训练，不能隔离当前读出模块的责任。 |
| [TAPIR，ICCV 2023](https://arxiv.org/abs/2306.08637) | 查询点匹配结合局部细化，分别预测遮挡和位置误差超过阈值的概率。它提供监督匹配风险的思路；其置信度不自动在我们的分布上校准，相关峰值或熵也不是错误率保证。 |
| [OSTrack，ECCV 2022](https://arxiv.org/abs/2203.11991) | 模板与搜索图联合建模，按模板相关性提前淘汰候选，比分类显著性筛选更贴近指定目标。其目标条件化作用于特征提取，不能直接证明冻结 I-JEPA 上的细节选择有效。 |
| [STCN，NeurIPS 2021](https://arxiv.org/abs/2106.05210) | 多对象共享帧间对应，并用距离度量改善记忆节点覆盖。共享对应已有先例；匹配几何需要独立控制，不能把 lane 收益全归于剔除无关 token。 |
| [XMem，ECCV 2022](https://arxiv.org/abs/2207.07115) | 多级记忆、查询依赖的匹配通道权重及记忆整合。其通道 selection 不等于空间 token 筛选；记忆使用率也不等于变化幅度或校准误差。 |
| [Cutie，CVPR 2024](https://arxiv.org/abs/2310.12982) | 对象查询与对象记忆修正像素记忆读取中的干扰，贴近当前身份混入问题。它保留高分辨率像素路径，不能直接视为固定字节下的细节分配方案。 |
| [MemLearner，2026](https://arxiv.org/abs/2606.31734) | 预测相关的 query tokens 从历史 context 读取细粒度信息，支持视频生成。主实现全量微调视频 DiT；不是冻结表示的小型位移头。“让 world model 学会查询记忆”本身不能声称新颖。 |

V5.6 中，正确 lane 的 dx MSE 下降约 30%，单纯匹配自由度没有消除差距；增加对象运动组合覆盖使 fresh64 的水平 MSE 下降 22.34%，却加重已知 Dev 上 y-only 时的假 x 输出。这支持继续拆分访问范围、匹配几何和训练覆盖，尚不能唯一归责编码器或池化。相关输入、比较与限制见 [V5.6 归档](../results/wm/visual-v5_6-20261010/README.md)。

**本轮已注册的是 CPU 定位诊断，不是上述训练方法的实现。** [V5.7 协议](V5_7_EXECUTION_PROTOCOL.md) 在已看 Dev 上固定成本面，用真实 y 行、固定循环错配 y 行等 oracle 干预检查候选竞争；另交叉描述子原点、余弦/平方距离与 raw/pool 分辨率。它不训练共享头、选择器或记忆，也不构成新确认。oracle 使用特权标签；全 raw 比较不等字节；全局均值不保证只含背景。成本排序改善不能证明编码器无缺陷，阴性也不能证明原表示没有所需信息。

后续可检验两条路线：一是固定编码器与训练世界，在所有组获得相同首帧查询信息时比较共享二维对应头，并报告静止轴假位移、方向和误差；二是固定读取器与总字节预算，比较正确查询、错配查询和均匀细节分配，再独立校准匹配风险、测试写入后的状态误差。两者均需 FIT 内设计和新的确认数据。潜在贡献在于受控条件下可验证的资源—状态精度收益，不能仅由已知模块的组合或当前事后诊断建立。
