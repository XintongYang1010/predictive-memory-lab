# 首周实验协议

## 可检验的问题

旧预测是否在新证据到达后拖累连续预测？选择性修正是否优于保留、全清空和匹配随机干预？一个不看未来的小 controller 是否能超过简单规则？这些都是待测假设。

## 运行状态

每个分支保存整个 RealMotion `memory_dict`，另保留上一时刻已观察输入窗口。
状态包括 scene encoder、模式特征、世界方向预测位移、场景/actor 有效性、origin、heading、timestamp、模式先验。
上游 `glo_y_hat` 实际是世界方向的相对位移；残差计算必须加上保存的 origin。
特征提取不执行上游“把旧预测平移到其预测当前位置”的重对齐。

新增证据是从 previous_step 到 current_step 的真实观测；未来预测部分不用于判错。
每次策略调用从保存的先验重新算一次权重，不把同一残差递归乘进 posterior。
没有有效重叠时，重加权和选择性删除退化为 Keep；controller 会收到无证据标志。

## 分支监督

从当前策略诱导的每个更新前状态克隆四份完整状态。
在分支起点执行一次候选动作，后续沿用相同当前策略、相同真实观察日程和确定性局部随机种子。
比较公共绝对目标区间上的平均 ES。未来评分只发生在 `metrics.frame_scores`，不传回动作接口。

对于 4 秒事件，比较 4/5 秒两个更新；对于 5 秒事件，只比较当次输出。
因此不得把 5 秒事件称为“多步恢复实验”。各事件的动作比较严格配对，事件之间单列。

选择 ES 改善大于 0.01 的最佳操作；否则 Keep。权重为 `1 + min(max(gain,0),5)`。
Train-repair 训练；Dev 的分支分类损失选择 checkpoint；Calibration 决定 sigma/tau/阈值。
预先固定轮数后才评价确认集。所有轮次的监督均重新生成，不直接复用旧标签。

## 两类评价不要混用

`diagnostic.jsonl`：只改某一个决策，回答干预是否存在收益。标签/最佳分支是诊断 oracle，不能声称可部署。

`evaluation.jsonl`：策略在每次更新时间自主决定，不搜索未来最优分支。普通/冲突组固定来自原始 Keep 模型在 4 秒时的残差，所有方法使用同一组场景。

`summary.json`：按 scene 进行配对 bootstrap。单事件表每个场景只有一个事件；不把两个更新当独立场景。
正的改善量等于 `ES_keep - ES_method`，同时报告组内数量和 95% CI。

## 指标定义

ES 对轨迹向量按 `sqrt(有效帧数)` 归一化：

`sum_k p_k ||z_k-y|| - 0.5 sum_kl p_k p_l ||z_k-z_l||`。

minADE6 对六模式取最小平均距离；minFDE6 取最小终点距离；1-mode 指标用最高概率模式；miss threshold 为 2 米。
`b_minFDE6` 取最小 FDE 的模式再加 `(1-p)^2`。
固定上游代码实际对 `FDE + (1-p)^2` 的总和取最小值，另存为 `b_minFDE6_upstream`，避免混淆。
目标有效性掩码在同场景各分支完全相同。空目标会失败并保留错误，不静默丢弃。

## 继续 / 转向判断

1. 保留历史在普通场景是否有益？若全清空普遍最好，先核对官方基线、坐标、训练适配。
2. Drop-worst 是否优于同数量/同年龄 Random-drop？
3. Controller 是否在独立场景超过校准规则，同时没有明显损伤普通场景？
4. 若只观察到 oracle 收益，仍需证明可预测的动作选择能泛化。

本阶段没有构造人工冲突、遮挡或意图标签；high_conflict 只是新观察与旧预测的残差分组。
完整的 RSI 论证还需要固定监督与普通难例训练的计算预算匹配对照。`--rounds 3` 本身不提供该论证。
