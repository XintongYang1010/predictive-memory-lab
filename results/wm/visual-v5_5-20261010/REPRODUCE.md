# V5.5 module localization reproduction

This is posthoc diagnosis on the already inspected Dev640–895 population (256 worlds, two variants). No Test data, no P0 or memory-training gate. Original N/W reader and full prior V5.4 scene remain dependencies: https://github.com/XintongYang1010/predictive-memory-lab/releases/tag/visual-v5_4-20261010 . The source commit and full official I-JEPA weight hash are pinned in the archived receipts. The original pretrained weight is referenced, not duplicated.

1. Check out the V5.5 source commit listed in source_manifest.json. Verify all listed hashes. Obtain the full V5.4 scene and authenticate its archive_manifest.json against the prior_manifest_sha256 in scripts/v5_5_plan.json.
2. Obtain the separately frozen lane reader from the V5.5 FIT Release, or refit it with the exact existing FIT inputs: `python scripts/v5_5_lane_reader.py fit --scene OLD_V54_SCENE --out NEW_LANE_DIR`. No tuning/evaluation enters this fit; source and all FIT identities are checked. Kernel coefficients and basis are included in the archived model, so refitting is unnecessary for scoring.
3. The counterfactual cache includes all8 A/B/Y endpoint combinations for each episode, prequant pooled outputs and original-endpoint raw tokens from the same encoder calls. Original frames are encoded in the original batch shape/order and must match the earlier pooled features bitwise before interpretation. Every object-intervention edge is checked against its allowed pixel support.
4. From the same source, replay CPU scoring: `python scripts/score_v5_5.py --cache V55_SCENE/counterfactual_cache --prior-scene OLD_V54_SCENE --lane-model V55_SCENE/lane_reader --out NEW_REPORT_DIR`. Keep the V55_SCENE registration_publication.json, complete cache manifest and receipts in place. The source validates source/model/cache identities before scoring.
5. CPU structural audit: `python scripts/audit_v5_5_reader.py --help`. Its executed command and the exact original model/input hashes are in cpu_audit/execution.log and audit.json. Plotting commands are documented by execution_tools/make_figures.py --help.

The saved GPU controller command, owned step nonce, Slurm accounting, per-worker GPU receipts, log files, complete source, lane model and per-episode predictions form the execution record. The frozen global N/W reader and official encoder are dependencies already archived/referenced. All CIs are descriptive whole-world resamples (10,000, seed7812), conditional on opened Dev and fixed readers.
