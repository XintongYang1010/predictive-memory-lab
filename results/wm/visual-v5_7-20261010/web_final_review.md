# V5.7 网页端结果复核

这是结果发布后的外部建议，不是独立执行或新的实测结果。下述 2×2 平滑/采样消融尚未执行。

已回读[报告](https://github.com/XintongYang1010/predictive-memory-lab/blob/bce24623e4f1299378a6b26fdeb20ac05c26942d/results/wm/visual-v5_7-20261010/README.md)。**归因边界基本准确：正确 y 不能救回当前成本面的水平排序，简单中心化和距离替换也不能解释 Raw/Pool 差距。**

两点应保留：这不否定学习型二维对应读出的潜力；也只排除了**已测试的均值／度量改动作为充分修复**，没有排除上下文干扰。0.1415px 下界仅约束输出网格量化。

下一项最精确的是一个**平滑 × 粗采样重建的 2×2 算子消融**，继续复用同一 raw：

- \(R\)：原 raw16 按真实物理坐标双线性重建。
- \(B\)：原 4×4 平均核改为 stride1 的密集滑动平均，保留正确的核中心坐标。
- \(D\)：在原 pooled4 的物理中心取样，再按原双线性规则重建。

| 臂 | 改变 |
|---|---|
| \(R\) | 原 raw 基线 |
| \(BR\) | 平滑，保留密集采样 |
| \(DR\) | 粗采样与重建，不加原 4×4 平均核 |
| \(DBR\) | 平滑＋粗采样；必须复现旧 pool |

**关键实现控制：偶数核有半格中心偏移；不能把 pool4 上采样成16当作“仅平滑”。** 固定 ROI、候选、距离和归一化顺序；另报四臂所有候选都不触边的共同子集，避免边界补值支配结论。

可证伪读法：

- \(BR\) 已明显变差、\(DR\) 较好：支持空间平均本身损害当前匹配的定位能力。
- \(DR\) 明显变差、\(BR\) 较好：支持粗采样／重建是主要限制。
- 只有 \(DBR\) 大幅恶化：支持两者交互，不能硬分责任百分比。

这个对照仍把**采样与插值作为一个组合因素**，也不能检验 encoder 对真实像素平移的等变性。但它能直接检验一个更具体的机制：**目标位移线索在平均时已变弱，还是在稀疏网格重建后才被错误的成本梯度盖过。**
