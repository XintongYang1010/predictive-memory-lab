# 从训练诊断到可检验的 memory 研究

依据：用户提供的 Lecture 5 课堂整理，以及本仓库 V1/V2.1 原始实验复核。
下面列出研究假设和最小实验；没有将任何假设写成已验证的性能结论。

## 本次已经落实的改进

|课堂 insight|在这个项目中的具体用法|
|---|---|
|先检查初始损失|收益回归的零初始化 MSE 应为目标收益平方均值，不套用分类的 ln(C)|
|先拟合极小数据|最多 16 条 Train 事件、无 weight decay；同时检查相同特征是否对应冲突收益|
|读学习曲线|全 Train/Dev MSE、五种简单诊断基线、按动作收益、伤害比例；与完整策略结果分开|
|监控真实参数变化|记录 AdamW 实际参数差、裁剪前梯度范数、激活范围；零初始化层的比值记为未定义|
|先明确不变性|坐标系刚体变换、模式重排不改变 controller 证据；不把时间顺序或真实运动变化当不变性|
|方法有效不等于解释成立|残差大、单次分支能改善、收益可被预测、连续部署有效，是四个不同命题|

另外修复了一处指标不一致：V2.0 校准 reweight/decay 参数时用公共 50 帧窗口，
V2.1 改成最终完整 60 帧，与分支回归、Dev 选择及最终报告保持一致。
V2.1 已在 A100 跑通，部署仍全部 Keep，没有证明改善数值。

## V2.1 复核推动的 V3 实验

V2.1 共 14,400 条原始记录，最终 1,000 场景的 controller 与 Keep ES 都是 1.573144。
16 条 Train 事件可拟合，但正式训练在第 150 步的已记录 Dev MSE 最低，500 步时更差。
Dev 第 5 秒单次干预的事后最优最终 ES 改善约 0.09418（7.26%），不是可部署结果。
该阶段残差与 Reset 收益的 Pearson 相关约 0.007；仅此不能排除非线性关系或样本量因素。
证据支持检验新输入，尚不能断言特征不足是唯一原因。

V3 已实现优先级 1 的第一阶段：原 14 维 → 加时间结构的 26 维 → 加直接影响度探测的 31 维。
这次使用目标盲的 Keep/Reset 输出差异作为输入；三组在推理时都执行相同的探测并报告开销。
先检验这些信息是否有预测价值，再决定是否值得训练无探测的蒸馏器。
下面提出的影响度辅助监督/蒸馏、混合前缀采样以及可变历史训练尚未实现。
新版本还保存每个候选的完整 Dev rollout 和权重，自动重算筛选，避免继续只保留汇总区间。

## 按以下顺序读新日志

1. 在 `diagnostics.json` 看各阶段可用动作的 oracle gain。如果几乎没有收益空间，先检查动作是否足够有用。
2. 看 `tiny_overfit`。拟合不动时查优化、数值尺度或特征冲突；这不是自动判定 bug 的规则。
3. 看 Dev 的 `zero_gain`、`train_mean_gain`、`stage_mean_gain`、`residual_ridge` 和 `all_feature_ridge`。
   MLP 若还不如常量或阶段均值，不能仅凭训练损失下降就认为它学会了 memory 修正。
4. 看完整 Dev rollout。离线单次编辑有收益、完整运行却没有，优先调查自己动作造成的后续状态变化。
5. 最后看未参与选择的完整评估。已查看的 V1/V2 验证场景是探索集；正式结论需要新场景和多个种子。

## 优先级 1：持续冲突与下游影响共同决定是否修正

**假设。** 相同大小的旧预测残差可能对应不同情况：短时噪声、模式不确定性或持续方向性偏差；
并且误差只有在被模型继续利用时才可能造成明显损伤。
V2 的 14 维特征将新观测段压缩成 RMSE 等汇总量，丢失了误差的时间结构。

**候选方法。** 使用仅来自已观察重叠段的逐模式残差趋势、方向一致性、连续超阈比例；
再用一个小模型预测编辑收益。对 memory 影响度的昂贵诊断可在训练时对 Keep/Reset 做成对前向，
将输出差异作为辅助监督，而不是在推理时额外看未来。
对称变换应该保持证据，真实转向和冲突持续时间应该改变证据。

**最小实验。** 在相同 Train/Dev 划分、相同动作集合、相同推理调用预算下，比较：
仅残差 → 当前 14 维 → 加时间结构 → 再加影响度辅助监督。
所有新增目标只在 Train 生成；Dev 用于选择，确认集最后评估。
额外前向必须计入训练预算，并设置同等骨干调用次数的对照。
按阶段和普通/高残差组报告收益、伤害率、动作频率、实际延迟。

**否证条件。** 新证据无法在新场景比阶段均值或残差模型更好地预测编辑收益，
或离线改善在完整 rollout 中消失，则停止扩大小网络；重新考虑动作粒度和特征来源。

**创新边界。** V2 已有收益回归，换一个名字不是新贡献。
候选贡献在于区分误差来源和下游影响，并用受控证据证明这种区分能改善部署选择。
“反事实轨迹预测”本身已有工作 [3]；这里是模型内部 memory 编辑的成对比较，
不能据此声称识别了真实交通世界的因果关系。

## 优先级 2：覆盖策略会遇到的 memory 状态

**假设。** controller 在 Keep 产生的状态上学会单次编辑后，会在部署中遇到自己修改过的 memory，
从而出现状态分布偏移。尤其当筛选一直回退 Keep 时，多轮训练仍可能重复同样的状态。

**候选方法。** 训练时混合 Keep、随机合法动作前缀、当前 controller 三类历史，
每种前缀都通过真实模型前向产生完整合法状态，再为该状态重新生成全部动作的最终 ES 标签。
评估时使用确定性的收益门槛和 Keep 回退。随机状态下旧标签不能直接复用。
不直接向隐藏张量注入任意噪声，因为那可能制造模型从未能产生的状态。

**最小实验。** 固定骨干前向调用总数，比较 Keep-only 数据、随机前缀数据和 on-policy 刷新数据。
同时记录状态覆盖、Train/Dev 差距、完整策略收益；不同采集策略必须使用相同场景边界。
若混合采集的收益只来自更多数据或更多计算，就不能归因为 RSI。

**创新边界。** 由自身动作造成的分布偏移及迭代数据采集是 DAgger 等已有研究的核心问题 [4]。
本项目需证明 memory 编辑的特定难点，以及为何状态构造/收益目标比预算匹配的普通数据聚合更有效。
单纯加轮数或随机 dropout 不是充分的创新。

## 优先级 3：在有用历史与当前证据之间学习可控的依赖

**假设。** 一个只习惯完整历史的预测器可能在 memory 修正后失效；
完全取消历史训练又会丢失其价值。训练应同时支持有历史和受限历史，并学会何时需要历史。

**候选实验。** 先比较完整历史与合法缺失历史的鲁棒性，保持真实时间戳、有效性掩码、运动/地图坐标一致。
若研究扩展到 history guidance，可把“某帧值得保留”定义为在固定帧/计算预算下对后续动力学预测的边际收益，
而非 attention 或新颖程度本身；训练时用删除/保留分支生成监督，推理只运行轻量选择器。

**边界。** 这需要训练预测器或改变输入日程，超出本次冻结骨干代码修正。
SHARP 已在短窗口 streaming 中联合训练长期上下文与单窗口预测，并研究不同观测长度 [2]。
必须与这类方法比较，不能将“随机少看历史 + 推理全用历史”直接称为新方法。
当前 3/4/5 秒三个更新时间也不足以支持长期 memory 恢复的主张。
