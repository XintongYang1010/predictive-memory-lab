# V5.1 posthoc prediction diagnostics

These diagnostics reopen completed frozen-reader reports and preserve their primary decisions. No fitting, candidate switching, new gate, or Test access occurs. Numeric reproduction uses a 1e-12 tolerance; verification.json separately records bitwise equality and exact decision agreement.

Each role contains all coordinate residuals, per-coordinate metrics, three prediction plots, and whole-group error rankings. Ranking uses primary concat motion MSE averaged over every view/variant and all four motion dimensions, with ascending ID ties. The two worst confirmation blocks are re-rendered only after their completed report is verified. Displayed labels are posthoc analysis metadata.

If a bridge report exists, reflection strata preserve both variants of every world. They describe boundary crossings from t6 to t7; strata differ in geometry and difficulty, so differences are not causal effects. They do not change the registered acceptance criterion.
