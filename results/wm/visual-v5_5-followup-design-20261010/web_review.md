## 网页端回复原文

已回读 [857a7db 最终解释](https://github.com/XintongYang1010/predictive-memory-lab/blob/857a7db/results/wm/visual-v5_5-20261010/final_interpretation.md)、lane 实现和 FIT 生成器。**下一步应拆分“信号经过哪条路径影响预测”与“哪种训练约束能改善泛化”**，目前还不能把剩余错误唯一归给 encoder、pool 或 reader。

先补一个 bad-case 边界：**B-only 同时改变 B 的 x、y**。891/1 的 `+.303px` 说明对这次二维运动的水平读出不足，但尚不能区分水平敏感度不足、`dy→dx` 串扰或两者抵消。

建议以下四项，前三项优先使用现有缓存；第四项才涉及登记新的训练图像。以下均为设计建议，没有运行。

1. **在共同特征映射内拆分 lane 访问与核几何。**

   [当前实现](https://github.com/XintongYang1010/predictive-memory-lab/blob/857a7db/scripts/v5_5_lane_reader.py)会分别重算 lane 的两级归一化，因此相同 alpha 不代表相同有效惩罚。

   更干净的对照是固定完整输入的 FIT 均值、两级尺度、自由截距和逐系数惩罚，将同一个二次特征映射按区域拆成：
   \[
   K_{\mathrm{full}}=K_L+K_R+K_{LR}.
   \]
   其中 \(K_L,K_R\) 包含各区域内部的线性、二次项，\(K_{LR}\) 是跨区域乘积；每个区域仍包含两帧。所有分量沿用共同归一化，**删项后不重新归一化**。

   最小三个模型是完整核、去掉 \(K_{LR}\) 的加性核、只保留目标所在区域的核，监督均为同一批 FIT。这样：

   - 加性核改善，而两边特征仍可访问：支持跨区域乘积及其估计方式造成限制。
   - 进一步限制访问才改善：支持非目标区域的可用函数仍会妨碍泛化。
   - 原 lane 有优势、共同映射下优势消失：原收益可能主要依赖重新归一化和正则几何。

   再用 **FIT 谱、无标签地匹配有效自由度**做一次复杂度敏感性检查，不能用 Dev 选 alpha。有效自由度相同也只匹配一个标量，不能宣称完整几何相同。正确 lane 与反向 lane 可作为同维度位置对照，但区域位置仍不等于对象身份。

   核心限制是：删除信息必然改变可表达函数和核；不存在“信息访问不同、所有训练及查询核却完全相同”的非平凡隔离。这里隔离的是明确的函数项和惩罚规则。

2. **把黄色像素干预与 token 替换连接起来，定位计算路径。**

   利用已有八条件，对每个固定 A/B 状态取 yellow 两端，得到末帧特征 \(z^0,z^1\)。保持第一帧、reader 和归一化完全冻结。预先划定区域 \(L\) 与其补集，构造四种输入：
   \[
   (z_L^0,z_{\bar L}^0),\quad
   (z_L^1,z_{\bar L}^0),\quad
   (z_L^0,z_{\bar L}^1),\quad
   (z_L^1,z_{\bar L}^1).
   \]
   报告两个替换效应及交互项，两个替换顺序都保留。

   解释必须分层：

   - 黄色像素变化使**不覆盖黄色新旧像素支持的池化块**发生变化：支持上游上下文传播。对这样的块，局部平均池化不能直接把别处黄色像素搬进来。
   - 仅替换这些区域的特征就改变目标运动预测：进一步表明 reader 使用了这条上下文响应路径。
   - 效应主要来自补集：支持显式访问其他区域的读出路径。
   - 单独替换很弱、联合替换很强：说明交互重要，不能分配独立责任百分比。

   **“encoder 携带黄色信息”和“reader 把它串读成目标运动”可以同时成立。** 特征含上下文本身不是编码错误。

   两个风险尤其重要：lane 中部分池化块本来覆盖黄色，不能称为干净目标区域；混合 token 未必对应任何真实图像，因此这是模型内部的计算干预，不是天然可识别的因果中介比例。当前全部条件只有 pooled/prequant 缓存，raw 仅有原始端点，不能声称做了 raw 级黄色定位。

   若随后要追查自身错向，可登记单目标的 `(dx,0)`、`(0,dy)`，与已有静止、完整二维运动组成小型像素 2×2；这才直接区分水平响应与轴间串扰。

3. **用同一对应规则比较 raw 与池化投影，检验可访问的空间信号。**

   令 \(Z\) 为现有 raw，\(QZ\) 为池化后重新展开到原网格的场。两者使用相同物理位移搜索网格、插值规则、距离函数、搜索范围和源帧对象选择规则，比较同一固定局部匹配器的结果。使用保存前池化，避免夹带最后一次 BF16 舍入差异。

   源帧颜色/真值 ROI 若被使用，明确标为特权诊断；不能再用真实 t7 对象位置限制搜索，否则会把答案送进去。除位移误差、方向外，也报告匹配代价曲线及歧义程度。

   | 结果 | 可以支持的解释 |
   |---|---|
   | raw、pooled 都能匹配，原 reader 差 | 当前读出方式没有充分利用该规则可访问的信号 |
   | raw 好、pooled 差 | 池化削弱了这类对应规则可访问的信号 |
   | pooled 更好 | 被去掉的变化可能干扰该匹配器 |
   | 两者都差 | encoder 限制与匹配器不合适仍无法区分 |

   这能避免把监督训练覆盖差异引入 **raw/pooled 匹配器之间**的比较，却不能证明普遍的信息损失。当前没有匹配的 raw FIT，因此不能把“raw 新匹配器”与“pooled 已训练 KRR”的差直接命名为 pooling 效应。若后续需要监督比较，必须补齐共同 FIT，并交叉比较表示与读出方式。

4. **改变同一布局内的对象运动组合，检验组合覆盖，而非再次扩大位置范围。**

   [FIT 源码](https://github.com/XintongYang1010/predictive-memory-lab/blob/857a7db/scripts/v5_4_data.py)有一个值得检验的结构：每个 world 只有 `C−d、C、C+d` 三个联合目标姿态。四坐标的方向跨 world 独立抽样，因此不能称 A/B 全局方向相关；但**同一个布局内，两对象只沿固定组合往返**。

   一个严格匹配的小对照：

   - **J：联合路径监督**，保留现有四条中心往返路径。
   - **X：交叉路径监督**，加入
     \[
     C\leftrightarrow C+(s_A d_A,s_B d_B),\qquad s_A,s_B\in\{-1,+1\}.
     \]
     共八条路径，全部与四种黄色路径完整交叉。
   - J 各路径重复两次以匹配行数；每 world 总损失权重相同。每个对象单独的起终点、方向、幅度分布和黄色路径分布相同。
   - X 只需五个联合目标姿态 × 两个黄色位置，即每 world 十张唯一图像，比原六张多四张。两臂使用共同 FIT 归一化，均重新冻结，随后评估 fresh worlds。

   主看 fresh bridge 误差、自身响应、跨对象假运动；保留黄色负控。X 若改善，支持同布局组合监督不足是可修复因素；若不改善，仍不能排除独立 world 数量、空间密度或 reader 机制。它也没有单独补齐 dx/dy 解耦覆盖。

   这个设计比简单增加视图数更有辨识力：重复 J 不增加经验分布的信息；X 改变的是联合监督约束。两臂共同的未标注归一化也应明确披露。

这些对照对应两条值得形成研究假说的方向：

- **对象对应与组合泛化。** 若 pooled 匹配有效、跨区域核项或组合监督影响显著，可以研究共享的对象对应读出：同一对象的位移响应应随运动保留，另一对象的变化应尽量不影响它。必须用对象跨区域、未见组合来区分对象分组与固定 lane 先验；先用 oracle 分组诊断，再验证仅凭观测产生的分组。
- **对象定向的记忆更新。** 后续可检验同容量下，分组写入是否减少干扰驱动的错误更新，同时保留真实目标更新；配合错误对象历史、错误历史顺序和冻结更新对照。当前 writer 不在路径，这只能是后续假说，不能解释 V5.5 的失败。

不建议把 attention 热图当机制证据、用全零 token 当“移除黄色”、比较不同物理分辨率的硬最近邻，或同时换 pool、reader、训练集后宣称单模块定位。尤其不能只看 sign-error 或假运动下降：把全部输出压向零也能改善部分读数，必须同时保留自身位移响应和绝对误差。

**执行优先级是①共同映射拆分 → ②缓存内路径干预 → ③共同网格匹配；④根据前面结果再登记。** 已见 Dev 继续作为探索诊断，任何修复确认另用冻结后释放的新数据，不改变原 gate、P0 或 Test 状态。
