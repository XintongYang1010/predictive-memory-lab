# V5.8 网页端结果复核与下一控制建议

收到真实报告之后的外部讨论；未代替独立数值审计，未执行这里提出的下一实验。本文件在科学归档冻结后保存，属于后续 Git 记录。

已回读[报告](https://github.com/XintongYang1010/predictive-memory-lab/tree/experiments/visual-v5_8-20261010/results/wm/visual-v5_8-20261010)。**归因准确，而且现在有排名与错向支持，已不只是平均误差变化。**

最重要的是：**大平均在密集网格上有害，在粗网格上却缓解误差。** 负交互说明作用取决于组合；不能根据 `DR−H` 较大就给采样分配更多“责任”，也尚未证明频谱混叠。

下一项优先做**同场 transport 闭环**，先只用原 raw 连续场 \(F=R\)，定位粗采样重建算子 \(D\)。令 \(T_\delta F(p)=F(p-\delta)\)，两臂固定同一个源场 \(DF\)：

1. **精确平移臂：**目标直接查询 \(T_\delta(DF)\)，不先栅格化再插值。
2. **重新采样臂：**目标为 \(D(T_\delta F)\)：先平移原连续场，再在原粗格点采样、重建。

这样比较的是  
\[
D T_\delta F-T_\delta D F,
\]
即**粗采样重建与平移不交换造成的差异**，源特征完全相同。

关键控制：

- \(\delta\) 事前固定且落在现有候选网格上，避免混入真值量化；仅比较所有查询及依赖采样点均不过界的共同集合。
- 精确臂的真值成本应为零至数值容差，但并列必须保留，不能强制真值胜出。
- 同时报特征差、GT成本排名及位移错误：非零特征差不一定造成定位失败。

**若重新采样臂也出现错向，**可证明该算子即使面对理想平移也足以破坏当前匹配；**若两臂都定位良好，**下一重点才是实际两帧不满足局部特征平移关系——可能来自前景／背景运动混合或上下文变化，仍不能单判 encoder。

精确臂成功是构造性正控，不是 encoder 等变性的证据。固定 bank 换插值规则可随后检验可恢复性，但单独改善不能证明采样没有损失信息。
